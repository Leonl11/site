# Photographer Portfolio - Dark Cinematic Elegance

## Overview
Сайт-візитівка для ню та художнього фотографа з Чернігова. Дизайн у стилі Dark Cinematic Elegance з масонрі-галереєю на 5 категорій (Boudoir, Природа, Арт-ню, Портрет, Чорно-біле), блоком конфіденційності, інтерактивним Lightbox та прямими контактами в Telegram та Instagram.

## Project Type
WEB (React 18 + Vite + Tailwind CSS + Framer Motion)
